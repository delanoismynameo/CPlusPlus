# Project Title: Seat Chart Application

This program reads a csv file with a people, days , and hours and tells the total

## Instructions for Build and Use

Steps to build and/or run the software:

1. Make a compatible csv.
2. On Vs Code press the play button to easily run the software.

Instructions for using the software:

1. Press the play button Vs Code
2. Input the amount of seats in the office

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:

* C++11 or Newer
* GCC (MinGW for Windows), Clang, or MSVC (Visual Studio)
* Standard Template Library (STL)
